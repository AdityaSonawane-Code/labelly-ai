# Labelly.AI on Vercel (free, Gemini)

1. Get a free key: https://aistudio.google.com/apikey  (sign in > Create API key). No card needed.
2. Put this folder on GitHub.
3. Vercel: Add New > Project > import the repo > Environment Variables:
   GEMINI_API_KEY = your key   (optional: GEMINI_MODEL, default gemini-2.5-flash)
4. Deploy and open the link.

Never put the key inside index.html.
